Tickets

Un bouton « Ouvrir un ticket » dans un salon de ton serveur : chaque ticket devient un salon privé entre le membre et le staff. Le staff peut aussi lire, répondre et fermer les tickets dans le 📂 panel des tickets.

Fonctionnement

Chaque ticket crée un salon visible seulement par le membre, le rôle staff et le bot, fermé avec le bouton 🔒. Le bot a besoin de « Gérer les salons » et « Gérer les rôles ».
Poste le message avec le bouton « Ouvrir un ticket » (ou le menu des types) dans le salon choisi. Déjà posté : il est mis à jour ; supprimé : il est reposté.

Messages envoyés au membre

Message d’accueil

Le message posté avec le bouton « Ouvrir un ticket » (ou le menu des types).

Types de demande

Le membre choisit un type au début. Sans type, le bot ne pose pas la question.

🤖 Assistant IA

L’IA répond en premier dans le salon du ticket. Elle se tait dès qu’un membre du staff écrit, ou quand le membre clique sur « Parler à l’équipe » (le rôle staff est alors mentionné).

Aperçu : panneau, salon du ticket et MP de fin

Bienvenue et au revoir

Accueille les nouveaux membres, vérifie qu’ils sont humains, donne-leur des rôles et préviens quand quelqu’un s’en va. Variables dans tous les textes : {user} (mention) · {name} · {server} · {count} (nombre de membres).

⚠️ Le bot ne reçoit pas encore les arrivées de membres. Active Server Members Intent dans le Developer Portal (onglet Bot) puis redémarre le bot : il le détecte tout seul. L’aperçu fonctionne quand même.

🛡️ Utiliser un captcha pour vérifier que les nouveaux membres sont humains

Comment régler le serveur pour le captcha
  1. Crée un rôle Vérifié (sous le rôle du bot) et choisis-le ci-dessus.
  2. Retire à @everyone la permission « Voir les salons » partout, sauf dans le salon de vérification.
  3. Donne « Voir les salons » au rôle Vérifié. Le bot poste le bouton de vérification à l’enregistrement.

🟣 Twitch — identifiants du bot

Seul toi (propriétaire du bot) vois ce cadre : ces identifiants servent aux alertes Twitch de tous les serveurs, et le secret n’est jamais réaffiché.

Comment obtenir ces identifiants (gratuit, 2 minutes)
  1. Va sur dev.twitch.tv/console/apps et connecte-toi avec ton compte Twitch.
  2. Clique sur Enregistrer votre application : un nom au choix, URL de redirection http://localhost, catégorie Chat Bot.
  3. Ouvre l’application, copie le Client ID, puis clique sur Nouveau secret et copie le Client Secret.
